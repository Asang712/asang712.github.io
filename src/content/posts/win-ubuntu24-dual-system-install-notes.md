# Windows + Ubuntu24.04 双系统完整踩坑实录

> 发布：2026-10 硬件：笔记本，NVIDIA独显，内存14G 目标：保留原有Windows，新增Ubuntu24.04，做开发环境

## 前言

最近需要Linux环境做开发，决定搭建Windows+Ubuntu24.04双系统。本以为照着教程一路下一步就能搞定，实际过程踩了超多坑，从U盘启动盘制作、分区、BitLocker、GRUB引导、显卡卡顿、时间不同步，一路调试，把全过程记录下来，给准备装双系统的同学避坑。

## 一、前期准备

1. U盘：8G以上空U盘，**优先插主板后置USB口（SS USB3.0）**，速度更稳，不容易写入失败。
2. 镜像：Ubuntu 24.04 LTS官方ISO镜像。
3. 工具：Rufus，用来制作启动盘。

### 制作U盘启动盘（踩坑点）

打开Rufus，选择U盘，导入Ubuntu镜像，写入模式选DD。 ⚠️ 坑：我第一次写入完成，误以为失败，重复点了一次开始，导致U盘被拆分成F、G两个分区。Windows识别不了Linux分区，弹出格式化提示，**千万不要点格式化**！

> 注意：启动盘还需要用来安装系统时，不要清理/合并U盘分区，等整套系统安装完毕后再处理U盘。

## 二、Windows磁盘分区（分配150GB给Ubuntu）

此步骤在Windows「磁盘管理」完成： 在数据盘压缩卷，腾出**150GB未分配空间**，不要新建简单卷，保持未分配状态，留给Ubuntu安装程序识别。

> 重点：不要动Windows系统盘分区！一旦误删，Windows直接崩溃。

### 额外前置操作

1. 关闭Windows【快速启动】，否则会导致Linux无法读取Windows分区。
2. BitLocker/设备加密：笔记本自带加密，**必须先解密**，不然Ubuntu安装程序无法识别硬盘分区，直接卡住安装。

## 三、BIOS启动，进入Ubuntu安装

1. 重启电脑，按主板快捷键进入BIOS，选择U盘启动项。
    
    > 坑：U盘启动加载很慢，笔记本独显容易黑屏卡死，启动时可以加`nomodeset`参数临时绕过显卡问题。
    
2. 安装向导流程

- 语言选择中文；
- 网络：按需连接；
- 安装类型：**最重要一步**，选择「安装Ubuntu，与Windows Boot Manager共存」（自动识别刚才预留的150G空闲空间），不要选清除整个磁盘！！
- 时区：选择上海（Ubuntu没有北京时区）；
- 创建用户名密码；
- 等待安装，安装完成提示重启时，**拔掉U盘**，再回车重启。

## 四、GRUB引导菜单设置

重启后会进入GRUB引导菜单，默认第一个选项是Ubuntu。 需求：修改启动顺序，默认开机优先进入Windows。 解决方案：修改GRUB配置文件，调整默认启动项；也可以直接在BIOS里调整硬盘启动优先级。

> 小缺点：GRUB菜单字体偏小，可以后续修改配置放大菜单文字。

## 五、安装后遇到的一系列问题与解决

### 1. 双系统时间不同步

现象：Ubuntu里时间正常，切回Windows时间错乱。 原理：Ubuntu默认把硬件时间当作UTC，Windows把硬件时间当作本地时间。 修复：在Ubuntu执行命令，修改硬件时间模式，统一使用本地时间。

### 2. Ubuntu界面卡顿（NVIDIA独显笔记本）

现象：桌面拖动窗口、点击菜单明显卡顿。 原因：默认使用GNOME Wayland会话，NVIDIA显卡兼容性差，系统跑在核显上。 解决：

1. 登录界面，点击齿轮图标，切换会话为 **Ubuntu Xorg**；
2. 安装NVIDIA官方闭源驱动；
3. 使用`prime-select`命令切换独显渲染，提升桌面性能。

### 3. 输入法使用体验差

Ubuntu自带输入法不太顺手，可以替换成Fcitx5+Rime中州韵，中文输入更流畅。

### 4. 密钥环弹窗

每次打开浏览器、钉钉等软件弹出密钥环解锁提示，要么设置自动登录，要么配置密钥环密码，按需取舍。

### 5. 软件安装

Ubuntu下安装软件选择`.deb`64位安装包，例如钉钉、微信，下载后终端执行安装命令。 我后续还尝试部署Trac项目管理系统。

## 六、总结&避坑清单

✅ 推荐做法

1. 预留150GB空间给Ubuntu，足够开发、存项目；
2. 制作启动盘只用DD模式，不要重复多次写入；
3. 安装前关闭快速启动、解密BitLocker；
4. NVIDIA笔记本优先Xorg会话+官方驱动，解决卡顿；
5. 安装完成立刻修复双系统时间同步。

❌ 千万别做

1. Ubuntu安装阶段，不要选择清除磁盘，会删掉Windows；
2. Rufus做完启动盘，Windows弹出格式化U盘，拒绝格式化；
3. 不要随意删除磁盘管理里的系统分区；
4. 没装完系统前，不要清理U盘分区。

这套双系统折腾下来，踩了很多细碎的坑，但是最终成功跑通。Windows用来日常办公，Ubuntu24.04专门做开发。如果你也要装同版本双系统，遇到GRUB、显卡、分区问题，可以参考本文。
